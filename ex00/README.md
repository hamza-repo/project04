# Personal Portfolio Website Hamza Al Mohammad

A personal portfolio website built from scratch for **Exercise 00: Personal Portfolio**. It introduces me, presents my technical skills and previous Web Piscine projects, shares my hobbies, and includes a contact form.

The website uses **HTML5, CSS3, and vanilla JavaScript (ES6+)**, without frameworks, templates, or UI libraries.

## Features

- **Header and navigation:** Links to the main sections of the page.
- **About Me:** A short professional introduction alongside a profile picture.
- **Skills:** A list of programming languages, development tools, databases, and other technical skills.
- **Project Showcase:** Summaries of Projects 00–03 (Linux/Git/GitHub, HTML, CSS, and JavaScript).
- **Hobbies:** A list of personal interests.
- **Contact Form:** Fields for name, email, and message, with built-in HTML validation.
- **Responsive styling:** Flexbox and CSS media queries adapt the layout to narrower screens.

**JavaScript requirement:** The exercise also requires a button that changes the background color or theme. Verify that this feature is implemented in `script.js` before marking the project complete.

## Technologies

- **HTML5:** Semantic structure (`header`, `nav`, `main`, `section`, `footer`), links, lists, and form controls.
- **CSS3:** Colors, spacing, Flexbox, responsive media queries, and theme-related classes.
- **JavaScript ES6+:** Event handling and DOM/CSS updates for the theme-switching feature.
- **Git:** Version control and submission.
